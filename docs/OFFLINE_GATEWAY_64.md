## Guarantee and trust boundary

- A local test supervisor supplies the approved manifest SHA, fresh approval serial, expiry, clock, SQLite path and trusted process/session tokens. These are simulations of external authority. The caller cannot vary payload fields or authority from an untrusted request. Use one supervisor-owned ledger file per campaign with local permissions. Host-admin, source-code modification, replacement/cloning of whole files, and falsified supervisor input are outside this simulation.
- SQLite `BEGIN IMMEDIATE` serializes reservations across connections and workers. Atomically record a worst-case ceiling before handing out a one-use permit. Reservation/intent/observation/settlement are separate append-only records. The second dispatch transaction checks STOP and runs the immediate fake observation under the same database lock. This keeps the simulated invocation ordered with the STOP transaction. The in-flight ceiling covers all unresolved reservations. The fake does not simulate parallel real network transfer.
- Integer micro-USD arithmetic rounds upward for token, regional, tax and per-call fee calculations. Fixed charges are declared as an already bounded all-in amount. Admit against US$8 and protect US$2. Retain the original slot for every attempt, including failed and ambiguous attempts. Original-suite allocation is separate from shared contingency and origin metrics. Diagnostics don't improve the performance failure denominator.
- No automatic retry. Only a settled synthetic rate-limit or transient failure can be the parent of one explicitly reserved retry using the same logical stage. Reservation age is bounded to 30 clock units per turn. Run clocks and approvals are trusted inputs in this simulation. No wire-token measurement, real backoff, or provider retry behavior is asserted.
- An observed timeout/partial receipt, inconsistent model/tier/rate/usage, expired approval, or stale outstanding permit denies dispatch. Crash recovery is a supervisor operation: restart rotates session/worker authority and sets STOPPED, preserving prior hard STOP reasons. Late permits cannot be reused. Outstanding amounts stay held. This implementation intentionally provides no synthetic override to release uncertain liability. After a clean restart only, a new explicit approval serial and validated history can resume with prior counters. No recovery from an uncertain liability is qualified.
